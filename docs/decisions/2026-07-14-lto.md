## Context

## Decision

1) SOURCE 层倒置为权威层级：runtime/source > COMMANDS 合同 > policy > active reference > 历史材料，文档与 runtime 冲突判文档漂移；2) 迁移顺序不可倒置：先修 reference truth（stale flags+checker 补覆盖）再建 INDEX 路由再切分超载文件最后压 SKILL；3) C4 可观性不单立机制，并入 autonomous_gate 做 current_run_observability 子检查；4) Python ledger evaluator 走退役方向（Rust 唯一判定源），修复排入 goal-c1。

## Consequences

SKILL.md 24K→8.3K 四层化；references 真实切分（playbooks/11、control-loop 现状/roadmap 分离）；checker 新增 5 类检查揪出 11 处漂移；4 份 core goal 文档（C1-C4）为后续实现 run 的派工载体；六域坐标以 references/INDEX.md 为唯一真源。
